# 📚 My Library (Django + React + DRF)

Personal library web application for managing books, reading progress, and book collections.

This project was created as a portfolio project to practice full-stack web development using Django REST Framework for the backend and React for the frontend.

The application helps users organize their personal library, track read and unread books, and manage authors, genres, and book series.

---

## 🚀 Current Version (Version 1)

### Features

- Add new books
- Edit existing books
- Delete books
- Mark books as read / unread
- Filter books by read status
- Filter books by author
- Pagination for book list
- Book detail modal
- Django admin panel
- REST API for books and authors
- SQLite database
- Responsive card layout using Bootstrap + custom CSS
